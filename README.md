# "Progress"
Прототип блока Progress для использования в мобильных web-приложениях.
Основное предназначение блока отображать процесс выполнения процессов и их прогресс выполнения.

![GitHub top language](https://img.shields.io/github/languages/top/RojnenkoFED/RojnenkoFED.github.io)

## Запуск демо
Открыть [страницу](https://rojnenkofed.github.io/src/) GitHub Pages

## Реализация
Компонент разработан с использованием пользовательских элементов (Custom Elements) и Shadow DOM.
Первое позволяет легко переиспользовать в других приложениях, а второе изолирует его разметку и стили.

При проектировании учитывался шаблон "стратегия" и его динамический выбор сущностей,
что позволяет легко добавлять новые параметры для компонента.

## Зависимости
Реализация компонента зависит от JS, поэтому следует указывать уведомление в случае его отключения.
В представленном демо это сделано с помощью ```noscript``` тега.

## Использование

У блока есть несколько состояний, которые можно задать с помощью атрибутов.

| Название       | Описание                                           |
|----------------|----------------------------------------------------|
| ```value```    | Управляет заполнением дуги от 0 до 100             |
| ```animated``` | Флаг запуска/остановки вращения по часовой стрелке |
| ```hidden```   | Флаг скрывающий/отображающий компонент             |

Также есть возможность настроить визульный стиль компонента с помощью кастомных CSS свойств.

| Название                | Описание                                  |
|-------------------------|-------------------------------------------|
| ```--size```	          | Размер (ширина/высота) компонента         |
| ```--bar-width```       | Ширина дуги                               |
| ```--fill-color```      | Цвет заполнения                           |
| ```--rest-color```      | Цвет фона                                 |
| ```--rotate-duration``` | Длительность (скорость) анимации вращения |
